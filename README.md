# 🔨 Игра "Удар молотом"

## 📜 Описание игры

Игроку необходимо ударить молотом в нужный момент, чтобы набрать максимальную силу и выиграть приз — **Рубин**. Сила удара отображается на шкале, которая постоянно и хаотично изменяется. Успех зависит от точности попадания по индикатору.

---

## 🎮 Игровая логика

### 🟢 Стартовый экран
- Приветственный текст.
- Пустая шкала силы.
- Кнопка **"Начать игру"**.

### 🕹️ Основной процесс
- После старта отображаются:
    - Кнопка **"Удар"**.
    - Шкала силы удара, постоянно изменяющая значение.
    - Инструкции для игрока: _"Нажмите на кнопку в нужный момент, чтобы ударить молотом!"_

### 💥 Удар
- По нажатию на кнопку:
    - Запускается **анимация удара молота**.
    - Шкала фиксируется на текущем значении.
    - Отображается сила удара.

### 🏁 Завершение
- После завершения анимации:
    - Выводится результат (победа/промах).
    - Появляется кнопка **"Играть снова"**.
